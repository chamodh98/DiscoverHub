# DiscoverHub

This app pulls together live info on News, Weather, Currency rates, and popular GitHub repos — and it was a great opportunity to level up my iOS development skills.

## 🚀 Tech Highlights

- 🎨 **SwiftUI** — Built the entire app using SwiftUI. Created custom UI components like a Floating Tab Bar, Skeleton loaders, and distinct Error and Empty state views.
- 🏗️ **MVVM Architecture** — Used MVVM to cleanly separate the UI and business logic from API calls.
- 🌐 **REST APIs** — Integrated multiple public APIs (News, OpenWeather, Exchange Rate, GitHub) with proper error handling.
- ⚡ **Combine Framework** — Used the Combine framework to handle asynchronous data flow reactively.
- 🧪 **Unit Testing** — Wrote tests for ViewModels and Services using mock dependencies to ensure reliability.
- 🔄 **CI/CD with Jenkins + Fastlane** — Set up a local Jenkins pipeline with Fastlane to automate app builds and run test cases.
